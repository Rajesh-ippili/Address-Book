# Address Book Management System

## 1. Project Introduction
The Address Book Management System is a menu-driven application developed using C programming. It allows users to store, manage, search, and maintain contact information efficiently.

## 2. Project Objective
- To develop a contact management application using C.
- To understand file handling concepts.
- To implement structures and pointers.
- To perform CRUD operations (Create, Read, Update, Delete).
- To store and retrieve contact details permanently.

## 3. Technologies Used
- Programming Language: C
- Compiler: GCC
- Platform: Linux
- Concepts: File Handling, Structures, Pointers

## 4. Features
- Add New Contact
- Search Existing Contact
- Edit Contact Details
- Delete Contact
- Display All Contacts
- Store Contact Information in Files

## 5. Functions and Their Purposes
- Add Contact: Adds new contact information.
- Search Contact: Searches for a particular contact.
- Edit Contact: Modifies existing contact details.
- Delete Contact: Removes a contact from the address book.
- Display Contacts: Displays stored contact information.
